## Update of 23 October 2026

The new update ZIP and current Sources tree omit historical Microsoft/MITS BASIC
runtime binaries and their derived RAM images. Program launch entries reference
an existing local installation. Earlier releases retain their historical notices.
The new panel artwork was generated with AI from a user-provided photo reference;
dynamic elements are rendered by HDL.

## Distribution scope

This prototype release includes FPGA binaries, source files, historical programs, documentation and screenshots. Component licenses and provenance are retained separately. No blanket license applies to the whole collection, and redistribution permission for the Microsoft/MITS BASIC runtime has not been established by this project.
